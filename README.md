# Стальной Полигон

**Стальной Полигон** — одиночная 3D PvE-танковая арена с кампанией из шести секторов, волнами противников, боссами и развитием боевой машины. Проект использует Three.js для 3D-сцены, React для оболочки интерфейса и Vite для локального запуска и сборки.

## Требования

- Node.js 20 LTS или более новая совместимая LTS-версия.
- npm (поставляется вместе с Node.js).
- Современный браузер с поддержкой WebGL и Web Audio API.

## Установка и запуск

Из корневой папки проекта выполните:

```bash
npm ci
npm run dev
```

Vite запустит сервер на порту `3000`. Откройте адрес, который он выведет в терминал (обычно `http://localhost:3000`).

## Проверки

```bash
npm run typecheck
npm run build
```

- `npm run typecheck` запускает TypeScript без генерации файлов.
- `npm run build` создаёт production-сборку в `dist/`.

## Управление

| Действие | Управление |
| --- | --- |
| Движение танка | W, A, S, D |
| Наведение и стрельба | Мышь, левая кнопка мыши |
| Форсаж | Shift |
| Мины (если доступны выбранному классу) | Правая кнопка мыши |
| Улучшение систем | Клавиши 1–7 |
| Пауза / меню эволюции | Esc или P |

Первый клик по арене может захватить указатель мыши. Для освобождения указателя используйте Esc.

## Настройки звука

Звуковые эффекты синтезируются через Web Audio API, внешние аудиофайлы не требуются. Громкость эффектов регулируется в настройках, а кнопка звука включает и выключает эффекты. Текущая версия не воспроизводит фоновую музыку; ползунок громкости музыки пока не управляет отдельным аудиоканалом.

Настройки громкости и чувствительности камеры сохраняются в локальном хранилище браузера.

## Структура проекта

- `src/App.tsx` — интерфейс игры и элементы экранов.
- `src/main.tsx` — точка входа React.
- `src/game/game.js` — игровой цикл, ввод, состояние кампании и переходы между этапами.
- `src/game/world.js` — 3D-мир и рендеринг.
- `src/game/player.js` — игрок, характеристики и развитие танка.
- `src/game/entities.js` — противники, снаряды, боссы и игровые объекты.
- `src/game/config.js` — характеристики, классы, главы и волны.
- `src/game/audio.js` — синтез звуковых эффектов.
- `src/game/ui.js` — HUD, экраны, настройки и локальное сохранение параметров.

## Технологии

React, TypeScript, JavaScript ES modules, Three.js, Web Audio API, Vite и Tailwind CSS через плагин Vite.
